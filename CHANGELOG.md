# Changelog

## 1.2.0

- Вкладка «EFI»: все EFI-разделы и FAT32-разделы флешек, отметка загрузочного раздела (по `boot-path` OpenCore),
  версия OpenCore, что лежит внутри (config.plist, кексты, драйверы, папки других систем).
- Монтирование и отключение EFI одной кнопкой, открытие в Finder, резервная копия всей папки EFI.
- Перенос EFI (например, с флешки на внутренний SSD): копирует EFI/OC и EFI/BOOT, прежние сохраняет в
  «Документы/EFI-backups», сверяет копию с источником и при любой ошибке возвращает цель как было. Папки других
  систем (Microsoft, Linux) не трогаются. Перед копированием проверяется свободное место.

## 1.1.0

- Встроенный исправленный Metal-плагин для драйвера 2.0.0 ставится одной кнопкой, оригинал сохраняется.
- Плагин: вылет Minecraft после асинхронной загрузки текстуры (драйвер отключал GPU в процессе), очередь
  асинхронных загрузок с лимитом, release-сборка без отладочного журнала.
- Вкладка «Игры и производительность»: настройки драйвера только для одной программы.
- DMG с инструкцией и помощником первого запуска (Gatekeeper).
- Своя иконка.

## 1.0.0

- Состояние системы, список релизов с GitHub, скачивание с проверкой SHA-256, установка через `install.sh`,
  проверка без изменений, удаление, очистка кэша шейдеров.
