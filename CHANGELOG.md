# Changelog

## 1.1.0

- Встроенный исправленный Metal-плагин для драйвера 2.0.0 ставится одной кнопкой, оригинал сохраняется.
- Плагин: вылет Minecraft после асинхронной загрузки текстуры (драйвер отключал GPU в процессе), очередь
  асинхронных загрузок с лимитом, release-сборка без отладочного журнала.
- Вкладка «Игры и производительность»: настройки драйвера только для одной программы.
- DMG с инструкцией и помощником первого запуска (Gatekeeper).
- Своя иконка.

## 1.0.0

- Состояние системы, список релизов с GitHub, скачивание с проверкой SHA-256, установка через `install.sh`,
  проверка без изменений, удаление, очистка кэша шейдеров.
