## Что умеет

| | |
|---|---|
| **Состояние системы** | видеокарта, версия macOS, загружены ли 4 кекста драйвера, установленная версия; предупреждает, если ноутбук работает от батареи |
| **Установка и обновление** | список релизов с GitHub (если GitHub недоступен, качает с зеркала автора), проверка SHA-256 пакета и каждого файла внутри, установка через официальный `install.sh` с выводом прямо в окне |
| **Проверка без изменений** | `install.sh` с `CHECK=1`: тестовая сборка kernel collection, в системе ничего не меняется |
| **Исправленный плагин** | встроенный Metal-плагин для драйвера 2.0.0 с исправлениями ([список](driver-patch/FIXES.md)); оригинал сохраняется, вернуть можно одной кнопкой |
| **Настройки для игр** | ключи драйвера только для одной программы (например `java` для Minecraft), не трогая WindowServer |
| **Сборка EFI** | OpenCore с нуля под этот компьютер: железо → кексты (build-repo, SHA-256) → SSDT → config.plist по Dortania + NullMoth → `ocvalidate` → отчёт с отличиями от текущей EFI |
| **EFI** | все EFI-разделы и флешки с OpenCore, какой из них загрузочный, монтирование, резервная копия, перенос EFI с флешки на SSD с проверкой и откатом |
| **Обслуживание** | очистка кэша шейдеров, удаление драйвера, логи всех установок |

Конфиг OpenCore программа **не меняет**. Если ставишь драйвер впервые, сначала настрой OpenCore по
[README драйвера](https://github.com/nullmoth/nvidia-macos-driver#wiring-into-an-existing-opencore-setup)
или через официальное приложение 1401.

## Требования

- macOS 15 Sequoia, Intel Mac или ПК с OpenCore (x86_64)
- NVIDIA GTX 16 / RTX 20, 30, 40, 50 (Turing и новее)
- OpenCore уже настроен под драйвер: boot-args, SIP, `SecureBootModel = Disabled`

## Установка

1. Скачай `NullMoth-Updater-<версия>.dmg` со страницы [Releases](../../releases/latest).
2. Открой DMG и перетащи **NullMoth Updater** на папку **Applications**.
3. Запусти приложение. В первый раз, скорее всего, придётся [обойти Gatekeeper](#первый-запуск-gatekeeper).

### Первый запуск (Gatekeeper)

Приложение подписано без платного сертификата Apple, поэтому macOS при первом запуске скажет, что не может
проверить разработчика. Это делается один раз, выбери любой способ:

**А. Помощник в DMG.** Дважды щёлкни `Если не открывается.command`. Он снимает метку «скачано из интернета»
только с `/Applications/NullMoth Updater.app` и открывает приложение. Если macOS не даст запустить и сам
помощник, открой Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

**Б. Системные настройки.** Открой приложение → «Готово» → Системные настройки → Конфиденциальность и
безопасность → внизу «NullMoth Updater был заблокирован» → **«Всё равно открыть»** → пароль.

**В. Терминал.**
```bash
xattr -dr com.apple.quarantine "/Applications/NullMoth Updater.app"
```

## Как пользоваться

### Установить или обновить драйвер
1. Вкладка **«Драйвер»** → выбери версию (по умолчанию новейшая).
2. По желанию нажми **«Проверить без изменений»**.
3. **«Обновить / переустановить»** → пароль администратора → 3–5 минут ожидания (kmutil пересобирает kernel collection).
4. **«Перезагрузить»**. Если macOS попросит разрешить расширения, разреши и перезагрузись ещё раз.

### Исправленный плагин (для драйвера 2.0.0)
**«Ещё» → «Установить исправленный плагин (встроенный)»** → пароль → перезагрузка.
Вернуть оригинал: **«Ещё» → «Вернуть оригинальный плагин»**.

Что исправлено: зависание, когда completion-хендлер ждёт свой command buffer; утечка памяти в
`newBufferWithBytesNoCopy`; отключение GPU в процессе после асинхронной загрузки текстуры (вылет Minecraft);
гонки в ray tracing и ещё восемь багов. Release-сборка без отладочного журнала. Подробности и тесты —
в [driver-patch/FIXES.md](driver-patch/FIXES.md).

### Minecraft и другие игры
Вкладка **«Игры и производительность»** → программа `java` → включи нужное → **«Сохранить»** → полностью
перезапусти лаунчер.

| Настройка | Ключ | Эффект (замер на RTX 4070 Laptop) |
|---|---|---|
| Буферы CPU→GPU в видеопамяти | `NVMTL_SHARED_VRAM=1` | GPU читает их со скоростью 247 ГБ/с вместо 13 ГБ/с |
| Загрузка текстур без ожидания GPU | `NVMTL_ASYNC_TEX_UPLOAD=1` | убирает простой CPU при каждом `glTexSubImage2D` (экспериментально) |
| Ожидание GPU по событию | `NVRM_EVENT_WAIT=1` | меньше нагрузка на CPU |
| Без обнуления буферов на GPU | `NVMTL_ZERO_FILL=host` | быстрее создаются буферы |

Работает только с исправленным плагином: в `nvrm610.conf` пишутся строки вида `java:КЛЮЧ=значение`, а
обычный плагин их пропускает.

### Сборка EFI с нуля
Вкладка **«Сборка EFI»** → **«Собрать EFI»**. Сборщик:
1. определяет железо (CPU, ноутбук/ПК, графику, сеть, Wi-Fi, NVMe, звук, дерево ACPI);
2. качает OpenCore и кексты из [dortania/build-repo](https://github.com/dortania/build-repo) и проверяет SHA-256 каждого архива;
3. подбирает SSDT по найденным путям ACPI;
4. собирает `config.plist` из `Sample.plist` той же версии OpenCore по правилам Dortania, с настройками драйвера NullMoth;
5. проверяет результат `ocvalidate` и пишет `ОТЧЁТ.txt`: что выбрано и почему, что отличается от текущей EFI.

С галочкой «Взять из текущей EFI…» (по умолчанию) из рабочей EFI переносятся SMBIOS (iCloud не заметит смены),
карта USB, AirportItlwm, патчи ядра, настройки BAR и твои boot-args. Для этого нужен пароль: EFI-раздел читается только с правами root.

Сборка кладётся в «Документы/OpenCore-Builds», **загрузочную EFI сборщик не трогает**. Проверяй так: запиши сборку
на флешку (кнопка «Записать…» в той же вкладке), загрузись с неё через меню BIOS, и только если всё работает —
переноси на SSD во вкладке «EFI». Не загрузилось — вынь флешку, старая EFI на SSD цела.

Ограничения: правила написаны для Intel (10–14-е поколение) и драйвера NullMoth. AMD, Core Ultra и экзотические
пути ACPI сборщик не соберёт сам — он скажет об этом в отчёте.

### EFI: смонтировать, сохранить, перенести с флешки на SSD
Вкладка **«EFI»** показывает все EFI-разделы (и FAT32-разделы флешек) и отмечает тот, с которого загрузился
OpenCore. Для каждого есть кнопки: смонтировать или отключить, открыть в Finder, сделать резервную копию папки EFI
в «Документы/EFI-backups».

**Перенос EFI**, чтобы грузиться без флешки:
1. Вставь флешку с рабочим OpenCore.
2. «Откуда» — флешка, «Куда» — EFI внутреннего SSD.
3. **«Перенести EFI…»** → пароль.

Копируются только `EFI/OC` и `EFI/BOOT`. Прежние сохраняются, копия сверяется с источником, при ошибке цель
возвращается как было. Папки `EFI/Microsoft` и другие не трогаются. Потом в загрузочном меню BIOS (обычно F12,
F11 или Esc) выбери внутренний диск. Если пункта нет, добавь в BIOS загрузочную запись на
`\EFI\OC\OpenCore.efi` или `\EFI\BOOT\BOOTx64.efi`. Флешку держи под рукой, пока не убедишься, что всё грузится.

## Если что-то пошло не так

- Логи: `~/Library/Logs/NullMothUpdater` (**«Ещё» → «Открыть папку логов»**).
- `install.sh` сам откатывает изменения, если установка не удалась.
- Если macOS не загружается: в меню OpenCore выбери **«1401: Remove NVIDIA driver»** (есть, если драйвер
  ставился через 1401), либо загрузись с boot-arg `-nvoff`.

## Сборка из исходников

Нужен Xcode 16+ (Swift 6) на macOS 15 x86_64.

```bash
./build.sh       # build/NullMoth Updater.app
./make_dmg.sh    # build/NullMoth-Updater-<версия>.dmg
```

Исправленный плагин собирается из исходников драйвера 2.0.0 с патчем `driver-patch/FIXES.patch`
(инструкция в [FIXES.md](driver-patch/FIXES.md#как-повторить-тесты)); готовая сборка лежит в
`driver-patch/NVMTLDriver`.
