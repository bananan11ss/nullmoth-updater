NullMoth Updater — установщик и обновлятор драйвера NullMoth NVIDIA для macOS 15
================================================================================

Что умеет
---------
• Показывает видеокарту, версию драйвера и загружены ли его 4 кекста.
• Скачивает релизы драйвера с GitHub автора (nullmoth/nvidia-macos-driver) или с его зеркала,
  проверяет SHA-256 и ставит их через официальный install.sh.
• Ставит исправленный Metal-плагин, который лежит внутри приложения: исправлены зависания, утечки и вылет
  Minecraft с асинхронной загрузкой текстур. Оригинальный плагин сохраняется, его можно вернуть.
• Вкладка «Игры и производительность»: настройки драйвера только для одной программы (например Minecraft).

Что нужно
---------
• Intel Mac или ПК с OpenCore, macOS 15 Sequoia, видеокарта NVIDIA RTX 20/30/40/50 или GTX 16.
• OpenCore уже настроен по README драйвера (boot-args, SIP, SecureBootModel). Конфиг OpenCore
  NullMoth Updater НЕ меняет. Если драйвер ставится впервые, сначала настрой OpenCore по README
  или через официальное приложение 1401.
• Ноутбук лучше держать на зарядке: на батарее видеокарта сильно урезана по мощности.


1. Установка приложения
-----------------------
Перетащи значок «NullMoth Updater» на папку «Applications» в этом окне.


2. Первый запуск (обход Gatekeeper)
-----------------------------------
Приложение подписано без сертификата Apple, поэтому при первом запуске macOS напишет
«Не удаётся проверить разработчика» или «Apple не может проверить…». Это нормально. Выбери один способ:

  Способ А — помощник (проще всего):
    1. Дважды щёлкни «Если не открывается.command» в этом окне.
    2. Если macOS не даст открыть и сам помощник: Системные настройки → Конфиденциальность и безопасность →
       внизу «Всё равно открыть» → введи пароль. Помощник снимет карантин и откроет NullMoth Updater.

  Способ Б — через Системные настройки:
    1. Открой «Программы» → дважды щёлкни NullMoth Updater → «Готово» в предупреждении.
    2. Системные настройки → Конфиденциальность и безопасность → прокрути вниз →
       «NullMoth Updater был заблокирован…» → «Всё равно открыть» → пароль.
    3. Снова открой приложение → «Открыть».

  Способ В — одна команда в Терминале:
    xattr -dr com.apple.quarantine "/Applications/NullMoth Updater.app"

Это нужно сделать один раз. Защиту системы помощник не отключает, он снимает метку только с этого приложения.


3. Установка или обновление драйвера
------------------------------------
1. Открой NullMoth Updater, вкладка «Драйвер».
2. В списке «Версия» выбери нужный релиз (обычно новейший).
3. «Проверить без изменений» — по желанию: тестовая сборка kernel collection, в системе ничего не меняется.
4. «Обновить / переустановить» → введи пароль администратора.
5. Подожди 3–5 минут, пока внизу не появится «Драйвер … установлен», потом нажми «Перезагрузить».
   Внизу окна идёт вывод установщика. Если что-то пошло не так, install.sh сам откатывает изменения.
6. Если macOS попросит разрешить расширения ядра (Конфиденциальность и безопасность), разреши
   и перезагрузись ещё раз.


4. Исправленный плагин (по желанию, для драйвера 2.0.0)
------------------------------------------------------
1. «Ещё» → «Установить исправленный плагин (встроенный)» → пароль.
2. Перезагрузись.
Вернуть оригинал: «Ещё» → «Вернуть оригинальный плагин».
Исправленный плагин собран из исходников 2.0.0 и ставится только поверх установленного драйвера 2.0.0.


5. Настройки для Minecraft
--------------------------
Вкладка «Игры и производительность» → программа «java» →
  • «Буферы CPU→GPU в видеопамяти» — GPU читает их в ~19 раз быстрее;
  • «Загружать текстуры без ожидания GPU» — меньше простоев в Minecraft (экспериментально);
→ «Сохранить для «java»» → полностью закрой и снова открой лаунчер.
Эти настройки работают только с исправленным плагином. WindowServer и другие программы их не видят.


Если что-то сломалось
---------------------
• Логи установки: ~/Library/Logs/NullMothUpdater (в приложении: «Ещё» → «Открыть папку логов»).
• Удалить драйвер: «Ещё» → «Удалить драйвер…», потом перезагрузка.
• Если после установки macOS не загружается, в меню OpenCore выбери «1401: Remove NVIDIA driver»
  (появляется, если драйвер ставили через приложение 1401). Либо загрузись с boot-arg -nvoff.

Драйвер: https://github.com/nullmoth/nvidia-macos-driver (лицензия PolyForm Noncommercial: бесплатно, продавать нельзя).
NullMoth Updater — неофициальная программа, к автору драйвера отношения не имеет.
Исходники и новые версии: https://github.com/bananan11ss/nullmoth-updater
